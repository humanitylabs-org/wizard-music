---
name: wizard-music
description: Play and search the owner's music library inside Music.
---
Use music_status first. If unconfigured, follow SETUP.md shipped with the app; never borrow another owner's token, library, or tunnel. music_home, music_search and music_account_library are read-only MCP tools. Use music_account_library with kind status/playlists/likes/playlist and a playlist id for playlist tracks; signed-out account library connects through /wizard-youtube-music/. Account library is bounded to 100 items, separate from Wizard taste, and does not imply playback entitlement or preferences sync. Browser playback is a user-gesture action in the Music view, not an MCP promise. Library scan and feedback use the documented API; use only owner-authorized files. Never claim native background playback from the web package.
